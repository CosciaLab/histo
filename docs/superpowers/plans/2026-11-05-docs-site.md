# Docs site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A MyST site on GitHub Pages with vignettes, how-tos, a generated parameter reference
with conflicts, outputs and visual QC, and a how-it-works wiki.

**Architecture:** `site/` is a MyST project that `{include}`s the nf-core docs unchanged and
reads generated Markdown from `site/_generated/`, written by `tools/site_reference.py` from the
schema, input-sheet schemas, `meta.yml` and `containers.tsv`. One workflow builds on every PR
and deploys from `main`.

**Tech Stack:** mystmd 1.12.0 (npm, pinned), Python ≥3.11 with PyYAML, pytest, GitHub Actions
(`actions/deploy-pages`).

**Spec:** `docs/superpowers/specs/2026-11-05-docs-site-design.md`

## Global Constraints

- Site URL `https://coscialab.github.io/histo/`; `BASE_URL=/histo` at build.
- Not an nf-core site: no nf-core logo or "nf-core/histo"; say "follows nf-core conventions".
- Do not move, rename or rewrite `docs/usage.md`, `docs/output.md`, `README.md`,
  `CHANGELOG.md`, `CITATIONS.md`. Link fixes inside them only if Task 1 proves they are needed.
- Never hand-edit `assets/params_template*.yml`; edit `nextflow_schema.json` by hand.
- No internal MDC paths (`/fast`, `/ceph`, `RD_Coscia`, `coruscant`) in `site/`, except what
  `docs/usage.md` already contains via include.
- Nextflow intro is one paragraph plus links to nextflow.io docs.
- Keep text short (CLAUDE.md §8): plain sentences, no repetition of `usage.md`; link its anchors.
- Every factual paragraph has a source comment under it: `% source: <file>#<section>` or
  `% source: <file>:<line>` or `% source: doi:<doi>`. MyST drops `%` lines from output.
- Paper figures only under CC BY, verified on the publisher page; caption ends
  `Reproduced from <cite>, CC BY 4.0.` Otherwise a figure slot.
- A figure slot is `:::{note} Figure pending: <what, from which run>\n:::` and is listed in
  `site/FIGURES.md`.
- Odon: one marked slot on the visual-QC page; nothing else.
- Commands use the version string in `docs/usage.md` quick start (currently `-r v2.0.0`).
- Commits: title < 60 chars, end with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push.

## Review Focus

1. Relative links inside included `docs/*.md` (`output.md#from-1x`, `../README.md`,
   `../assets/...`) must resolve on the site or point at GitHub; `--strict` catches internal ones
   (Task 1).
2. Schema parameters with no `default`, `null` default, enum, or `hidden: true` must render
   without crashing or printing `None` (Task 2 tests).
3. A parameter named in `validateParams`/`validateMarkersheet` but lacking a rule line is a doc
   gap; the coverage test pins it (Task 3).
4. Vignette `params.yml` snippets must pass the real startup checks (no `use_projection` with
   `cellpose_channels`, TMA needs both counts, etc.); Task 6 Step 2 checks each against
   `validateParams`.
5. A page under `BASE_URL=/histo` with absolute `/images/...` links breaks only on Pages; use
   relative paths, checked in the Task 1 build with `BASE_URL` set.

### Task 2: `tools/site_reference.py`

**Files:**

- Create: `tools/site_reference.py`, `tests/unit/test_site_reference.py`,
  `tests/unit/fixtures/site_schema.json` (tiny schema: one group, a string with `default`, an
  integer with no default, an enum, a boolean `hidden: true`, one with `help_text`)
- Modify: `pyproject.toml` (add `"pyyaml>=6"` to dev group, comment: read by
  `tools/site_reference.py`), `uv.lock`

**Interfaces:**

- Produces:
  - `render_parameters(schema: dict) -> str` — `## <group title>` per `$defs` group in
    `allOf` order, then `### \`<name>\` {#<name>}` per parameter with a definition list: Type,
Default (`none`when absent or null), Allowed (enum, if any), then description, then`help_text`. Hidden parameters collected into one `:::{dropdown} Hidden parameters` at the
    end.
  - `render_sheet(schema: dict, title: str) -> str` — a table `Column | Required | Type |
Description` from `items.properties` and `items.required`.
  - `render_module_facts(module_dirs: list[Path], containers_tsv: Path) -> str` — a table
    `Module | Tool | Version | Container | Paper`: tool name, homepage and `doi` from
    `meta.yml` `tools`; version and container from the `containers.tsv` row whose `modules`
    column lists the directory (conda spec if present, else the image tag).
  - `PAGES: dict[str, list[str]]` — how-it-works page slug → module dirs, e.g.
    `"ashlar": ["modules/nf-core/ashlar"]`, `"cellpose": ["modules/local/segment_patch"]`.
  - `main(repo: Path = REPO) -> None` — writes `site/_generated/parameters.md`,
    `site/_generated/samplesheet.md` (cycle, stitched and marker sections), and
    `site/_generated/modules/<slug>.md` per `PAGES` entry.
  - PEP 723 header `dependencies = ["pyyaml"]`, so `uv run tools/site_reference.py` works
    without the dev group.

**Interfaces:**

- Consumes: `subworkflows/local/utils_nfcore_histo_pipeline/main.nf` functions
  `validateParams`, `validateMarkersheet`, `validateProjectionGroups`, `checkReferenceChannels`;
  `subworkflows/local/segmentation/main.nf`; `subworkflows/local/preprocess_images/main.nf`.
- Produces: rule line format, exactly one line at the end of `help_text`, any subset in this
  order: `**Requires:** … **Conflicts:** … **Ignored unless:** …`

- [ ] **Step 1: Write the failing test**

```python
CHECK_FUNCS = ["validateParams", "validateMarkersheet", "validateProjectionGroups", "checkReferenceChannels"]
MARKERS = ("**Requires:**", "**Conflicts:**", "**Ignored unless:**")

def test_every_checked_param_has_a_rule():
    names = params_in_functions(UTILS_NF, CHECK_FUNCS) & schema_property_names()
    missing = [n for n in sorted(names) if not any(m in help_text(n) for m in MARKERS)]
    assert not missing, f"add a rule line to help_text of: {missing}"
```

`params_in_functions` takes each `def <name>(` body up to the next line starting with `def `,
and collects `params\.(\w+)` and `params\['(\w+)'\]`, plus string literals in
`STAINING_BASED_METHODS`. Expected uncovered today include `use_instanseg`,
`instanseg_pixel_size`, `use_projection`, `cellpose_channels`, `keep_projection`, `use_gpu`,
`instanseg_channels`, `use_tma_dearray`, `tma_expected_cores`, `tma_core_diameter_mm`,
`coreograph_args`, `quantification_statistics`, `preprocessing_only`, `use_backsub`.
