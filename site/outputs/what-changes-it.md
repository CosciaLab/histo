# What changes the outputs

Which parameter adds, removes or changes what, in `--outdir` and in the store. `{m}` is
`cellpose` or `instanseg`; `<image>` is the image element. Defaults are on the
[parameters](../reference/parameters.md) page.

| Parameter                                                                                                              | Effect on outdir                                                                                                                                                                                           | Effect on the store                                                                                                                                                                                                                           |
| ---------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`use_preprocessing`](../reference/parameters.md#use_preprocessing)                                                    | False: no `preprocessing/` and no Ashlar QC.                                                                                                                                                               | False: channel names are the image's own; the marker sheet does not rename them.                                                                                                                                                              |
| [`preprocessing_only`](../reference/parameters.md#preprocessing_only)                                                  | Only `preprocessing/` and `pipeline_info/`; Ashlar's QC still with `use_qc`.                                                                                                                               | No store.                                                                                                                                                                                                                                     |
| [`use_backsub`](../reference/parameters.md#use_backsub)                                                                | Adds `preprocessing/background_subtraction/{sample}_backsub.ome.tif` and `.csv`. The QC JSON adds channel statistics from before subtraction.                                                              | The image is the subtracted one, named `{sample}_backsub`, so cell ids start with it. Channels marked `remove` are gone.                                                                                                                      |
| [`use_tma_dearray`](../reference/parameters.md#use_tma_dearray)                                                        | Adds `preprocessing/dearray/`, and `dearray/sweep/` unless `coreograph_args` is set. One QC report per core and method, plus `qc/{slide}_{m}_slide_report.html`.                                           | `{slide}_merged.zarr` and `{slide}_merge_manifest.json` instead of per-core stores. Elements are named `{core_id}__{name}`, e.g. `TMA01_core001__cellpose_table`, except an image already named after the core; tables gain `obs['core_id']`. |
| [`use_tissue_segmentation`](../reference/parameters.md#use_tissue_segmentation)                                        | None.                                                                                                                                                                                                      | Adds `shapes/region_of_interest`; `image_patches` covers only the tissue.                                                                                                                                                                     |
| [`use_gpu`](../reference/parameters.md#use_gpu)                                                                        | None.                                                                                                                                                                                                      | None, apart from `gpu: true` in each entry of `uns['segmentation']`.                                                                                                                                                                          |
| [`use_projection`](../reference/parameters.md#use_projection)                                                          | Adds `qc/{sample}_projection.png` and `.json`.                                                                                                                                                             | Cellpose segments `<image>_projected`, which is then deleted unless `keep_projection`.                                                                                                                                                        |
| [`keep_projection`](../reference/parameters.md#keep_projection)                                                        | None.                                                                                                                                                                                                      | Keeps `images/<image>_projected`, channels `nuclear` and `cell`.                                                                                                                                                                              |
| [`use_cellpose`](../reference/parameters.md#use_cellpose), [`use_instanseg`](../reference/parameters.md#use_instanseg) | With `use_qc`, one `qc/{sample}_{m}_qc.json` and `_qc_report.html` per method, and `_qc_images/` with `use_qc_images`; with both methods segmenting cells, also `qc/{sample}_comparison.json` and `.html`. | Shapes `{m}_*` and `tables/{m}_table` per method.                                                                                                                                                                                             |
| [`segment_cells`](../reference/parameters.md#segment_cells)                                                            | False: no `qc/{sample}_comparison.*`.                                                                                                                                                                      | Adds `shapes/{m}_cells`; table rows are cells. False: rows are nuclei, with `nucleus_*` columns and no `cell_*`.                                                                                                                              |
| [`segment_nuclei`](../reference/parameters.md#segment_nuclei)                                                          | With `segment_cells`: the QC JSON adds `linking`.                                                                                                                                                          | Adds `shapes/{m}_nuclei`. With `segment_cells` also `shapes/{m}_cytoplasm`, `linked_cell_id` on the nuclei, table layers `nucleus` and `cytoplasm`, and `obs` columns `n_nuclei`, `nucleus_id`, `cytoplasm_area`, `nucleus_*`, `nc_ratio`.    |
| [`quantification_statistics`](../reference/parameters.md#quantification_statistics)                                    | None.                                                                                                                                                                                                      | One table column per marker and statistic, `{marker}_{statistic}`; also listed in `uns['quantification']`.                                                                                                                                    |
| [`expand_radius_ratio`](../reference/parameters.md#expand_radius_ratio)                                                | None.                                                                                                                                                                                                      | `X` is measured over the expanded cells. Layers, shape features and `obsm['spatial']` use the unexpanded ones.                                                                                                                                |
| [`use_qc`](../reference/parameters.md#use_qc)                                                                          | False: no QC reports or metrics in `qc/`, and no `{sample}_ashlar_qc/`.                                                                                                                                    | None: QC only reads the store.                                                                                                                                                                                                                |
| [`use_qc_images`](../reference/parameters.md#use_qc_images)                                                            | False: no `qc/{sample}_{m}_qc_images/`; the report keeps metrics and charts, without crops and clusters.                                                                                                   | None.                                                                                                                                                                                                                                         |
| [`publish_dir_mode`](../reference/parameters.md#publish_dir_mode)                                                      | How every file reaches `outdir`: `copy` (default), `copyNoFollow`, `move`, `link`, `symlink` or `rellink`. `symlink` and `rellink` point into `work/` and break when it is cleaned.                        | The store is published the same way.                                                                                                                                                                                                          |
